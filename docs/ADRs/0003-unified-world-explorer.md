# ADR 0003 - Unified World Explorer

Decision:
Use a unified page instead of separate pages.

Layout:
Top Hero

Middle Split View:
Left = Understanding Panel
Right = Interactive Panel

Bottom Sections:
- Failures
- Scaling
- Alternatives
- Burger Farm Code References
- Industry Examples

Reason:
Users should see and understand simultaneously.

Avoid tabs hiding information.

Goal:
Make worlds feel alive and interconnected.
