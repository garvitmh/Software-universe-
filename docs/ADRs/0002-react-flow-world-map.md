# ADR 0002 - React Flow World Map Navigation

Status: Accepted

Decision:
The homepage will be an interactive React Flow world map instead of a traditional dashboard.

Reason:
Software Universe teaches systems, not pages.

World nodes:
- Order World
- Payment World
- Delivery World
- Loyalty World
- POS World
- Analytics World
- Security World
- Deployment World

Each node expands into:
- Codex
- Simulator
- Failures
- Scaling
- Alternatives

Interaction:
- zoom and pan
- animated edges
- click node to enter world
- warm farm styling

Why React Flow:
- infinite canvas
- graph thinking
- expandable
- visual understanding

Alternatives considered:
- sidebar navigation
- cards dashboard
- tree navigation

Rejected because they encourage page thinking instead of system thinking.
